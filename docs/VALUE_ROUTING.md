# Research Value Routing

This is a product/research classification, not a valuation model.

- `CASH_ENGINE` — plausible near-term paid compute/verification/software use.
- `PLATFORM_BUILDER` — improves standards, infrastructure, tooling, or ecosystem.
- `LONG_DURATION_OPTION` — potentially high-value scientific/IP outcome with long uncertainty.
- `PUBLIC_GOOD` — useful science with limited direct commercialization.
- `RESTRICTED` — sensitive workload requiring stronger access/safety/compliance controls.

Store the reasons behind classifications.

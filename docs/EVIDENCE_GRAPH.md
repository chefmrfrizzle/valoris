# Evidence Graph

The Evidence Graph records **what happened and where it came from**.

```text
Question
→ ProblemPassport
→ Dataset / Input Artifact
→ Program / Build
→ TaskSpec
→ ExecutionReceipt
→ VerificationReceipt
→ ReproductionAttempt
→ AcceptanceReceipt
→ Claim / Publication / Commercial handoff
```

Every important edge is attributable, versioned, and auditable.

See `RESEARCH_RELIABILITY_GRAPH.md` for the cross-run memory of reliability.

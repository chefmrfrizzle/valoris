# Scientific Continuous Verification

```text
Observe
→ Record LearningEpisode
→ Link evidence and failures
→ Retrieve comparable history
→ Propose change
→ Build in isolation
→ Tests + evals + security gates
→ Compare with baseline
→ Approve / reject
→ Canary / release
→ Observe again
```

A `LearningEpisode` records:
- trigger;
- evidence references;
- baseline;
- proposed change;
- tests/evals;
- failures;
- security findings;
- decision;
- canary/release outcome.

Self-learning means evidence-driven improvement under gates, not unrestricted self-modification.

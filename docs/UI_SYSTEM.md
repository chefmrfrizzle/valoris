# UI System

## Principle

**Progressive disclosure:** plain language first, exact evidence on demand.

## Perspective switcher

### Explorer
What is the question? Why does it matter? How confident are we?

### Scientist
Hypothesis, assumptions, datasets, method, uncertainty, reproductions, challenges, counterexamples.

### Engineer
TaskSpec, build, runtime, hashes, worker, verifier, receipts, failure traces.

### Operator
Fleet health, queue, capacity, failures, disagreement, canary/release state.

### Security
Classification, policy gates, suspicious events, provenance integrity, dependency/release state.

## Main navigation

Explore | Problems | Work | Evidence | Reproduce | Challenges | Network | Operations

The Counterexample Track is shown beside supporting evidence rather than buried in an audit page.
